# 02 - Container

Ein `Container` ist eines der wichtigsten Anfänger-Widgets.

Du nutzt ihn für:

- Breite und Höhe
- Hintergrundfarbe
- Abstand innen (`padding`)
- Abstand außen (`margin`)
- Rahmen, runde Ecken und Schatten über `decoration`

## Neu in dieser Lektion

- `width`
- `height`
- `color`
- `padding`
- `margin`
- `BoxDecoration`

`MaterialApp`, `Scaffold`, `Center` und `Text` werden ab jetzt vorausgesetzt.
