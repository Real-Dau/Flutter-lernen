# 03 - Row und Column

`Row` und `Column` sind Layout-Widgets.

- `Row`: Widgets nebeneinander.
- `Column`: Widgets untereinander.

## Neue Begriffe

- `children`: mehrere untergeordnete Widgets.
- `mainAxisAlignment`: Ausrichtung auf der Hauptachse.
- `crossAxisAlignment`: Ausrichtung auf der Querachse.
- `Expanded`: nimmt freien Platz ein.

Was vorher erklärt wurde, wird vorausgesetzt. Wir erklären also nicht mehr jedes Mal `Scaffold` oder `Container`.
