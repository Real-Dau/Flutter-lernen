# Screenshots - 01-widgets-und-materialapp

> In diesem Ordner sammeln wir immer **Code-Screenshots** und die passenden **Resultat-Screenshots**.

---

## Dateinamen-Regel

- `01_code.png` = Screenshot vom ersten Beispiel im Editor
- `01_result.png` = Screenshot vom Ergebnis des ersten Beispiels
- `02_code.png` = Screenshot vom zweiten Beispiel im Editor
- `02_result.png` = Screenshot vom Ergebnis des zweiten Beispiels

Bei reinen Dart-Beispielen kann `*_result.png` auch ein Terminal-/Output-Screenshot sein.
