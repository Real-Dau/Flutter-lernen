# 11 - Dart Syntax Tricks

Ab hier wird die Syntax dichter. Das sind die Sachen, die am Anfang oft komisch aussehen.

## Themen

- `=>` Arrow Function
- `?`, `!`, `??` bei Null Safety
- `...` Spread Operator
- `if` in Listen
- `:` in Konstruktoren
- Cascade Operator `..`

Wichtig: Diese Lektion erklärt Syntax, die du später überall in Flutter-Code sehen wirst.
